# Configuration authority

`validation_protocol.yaml` defines the predetermined shared preprocessing and
evaluation protocol used for enhanced-algorithm validation. These values are
inputs to validation and are not selected using the test set.

`frozen_parameters.yaml` is the only configuration consumed by final testing
and the Streamlit application. It is generated by
`scripts/evaluation/run_essential_validation.py`, which selects the highest-F1
candidate for each algorithm on the 139-image validation split.

`legacy_raw_validation/` contains historical records from the earlier raw
parameter-selection experiments. They are retained for traceability but are not
final-test configuration files.
